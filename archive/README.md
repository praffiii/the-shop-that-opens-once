# Archive

## `godot-mvp/`

The Godot 4.7 (GDScript) MVP: Nights 1 and 2 of the earlier story, playable from start to finish. It was archived on 2026-10-18, when the game moved to Unity and to the redesigned story in the UTS GDD. Its files are exactly as they were; the git tag `godot-mvp` marks the last commit before the move.

- **Play it:** https://the-shop-that-opens-once-game.vercel.app
- **Open it:** import `godot-mvp/project.godot` in Godot 4.7 (the standard build). Its own `README.md` explains how it is built.
- **Its story is not canon.** Arthur Tate, the 18:17 clock and Nora the toymaker belong to the retired story. See `GAME-CONTEXT.md`.
- **Old paths:** the README's paths and the art exporter in `tools/export-art/` assume the old `game/` folder. For the exporter's original layout, check out the `godot-mvp` tag.
