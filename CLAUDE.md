# The Shop That Opens Once

- Read `GAME-CONTEXT.md` before any game design, story or development work. It is the source of truth: follow its Decisions, ask the user about the Open questions a task depends on, and record each new decision there with its date.
- The design comes from the UTS GDD (`docs/game-design-document.pdf`, in Indonesian). The earlier story (Arthur Tate, the 18:17 clock, Elise) is retired.
- The visual reference is the code-drawn pixel art in `presentation/`, with rules in `presentation/ART.md`. Make every asset from scratch: art drawn in code or by hand, sound synthesized. Never use AI-generated art, audio or assets.
- The game is being rebuilt in Unity 6.6 with C#. There is no Unity project yet; ask where it goes before creating it.
- `archive/godot-mvp/` is the archived Godot MVP. Read it for reference, but never change it.
