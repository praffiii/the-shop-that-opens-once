# The Shop That Opens Once

- Read `GAME-CONTEXT.md` before any game design, story or development work. It is the source of truth: follow its Decisions, ask the user about the Open questions a task depends on, and record each new decision there with its date.
- The visual reference is the code-drawn pixel art in `presentation/`, with rules in `presentation/ART.md`. Ask the user before using any AI-generated asset.
- The game is the Godot 4 project in `game/`, written in GDScript. `game/README.md` explains how it is built and how to write a night; run `game/tests/night_1_test.tscn` after changing it.
