# The Shop That Opens Once

A cozy, melancholic 2D pixel-art mystery. In the ant town of Bellwood, a shop appears for seven nights, and a courier returns its keepsakes to their owners.

A game project by SE.3 · Kelompok 1: Andika Rafa Akbar, Dara Dwi Hidayat, Khairul Insan, Piere Valkyrie and Praffi Ramadhani.

**Status:** concept stage. The team has not chosen the engine for the full game yet.

## What's in this repo

| Path | What it is |
| --- | --- |
| `GAME-CONTEXT.md` | The game's design summary: decisions, story, the seven nights and open questions. Start here. |
| `docs/` | The game design document and the feasibility report |
| `presentation/` | The web presentation and its code-drawn pixel art, the game's visual reference. Live at https://the-shop-that-opens-once.vercel.app |

The full game will get its own folder once the team picks an engine.

## Quick start

- **See the presentation:** open `presentation/the-shop-that-opens-once.html` in a browser. It works offline.
- **Change or publish the presentation:** see `presentation/README.md`.
