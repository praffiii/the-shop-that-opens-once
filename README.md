# The Shop That Opens Once

A cozy, melancholic 2D pixel-art mystery. In the ant town of Bellwood, a shop appears for seven nights, and a courier returns its keepsakes to their owners.

A game project by SE.3 · Kelompok 1: Andika Rafa Akbar, Dara Dwi Hidayat, Khairul Insan, Piere Valkyrie and Praffi Ramadhani.

**Status:** the first playable night. The game is built in Godot 4 (GDScript), and Night 1 plays from start to finish.

## What's in this repo

## Quick start

- **Play the game:** open `game/project.godot` in Godot 4.7 and press F5. See `game/README.md`.
- **See the presentation:** open `presentation/the-shop-that-opens-once.html` in a browser. It works offline.
- **Change or publish the presentation:** see `presentation/README.md`.
